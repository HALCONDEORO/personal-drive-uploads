Marco Personal Drive Uploads

Privacy policy

This policy describes the personal Google Drive upload tool operated by Marco Tevar.

Access to Google data

This tool requests only the Google Drive drive.file permission to create and manage files created or explicitly opened with the app. It does not request access to the whole Drive, Gmail or contacts.

How data is used

File contents and metadata are used only for the owner's requested uploads and checks. Google user data is not sold, used for advertising or used to train AI models.

Storage and security

Google authorization credentials are kept in encrypted credential storage and protected server files. Credentials and private file contents are never published on this website.

Owner controls

The owner can revoke access in Google Account settings and delete files in Google Drive. Local working copies can be deleted when they are no longer needed.

This public website

This site has no sign-in form, trackers or analytics added by the tool. GitHub Pages may process request data under GitHub's privacy policy.
