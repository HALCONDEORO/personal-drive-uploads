Marco Personal Drive Uploads

A personal tool operated by Marco Tevar to upload selected files to his own Google Drive.

This is not a public sign-up service. This website does not provide access to the owner's files.

What the tool does

It uploads selected files and checks their size and integrity. It requests only Google's drive.file permission to create and manage files created or explicitly opened with the app.

Read the privacy policy for details about data access and storage.
